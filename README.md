# Dockerized Flask Web App 🚀

This project is a simple Python Flask web application containerized using Docker and managed with GitHub.

It demonstrates the basics of DevOps:
- Version control using GitHub  
- Containerization using Docker  
- Application deployment using containers  

---

## 🔧 Technologies Used
- Python  
- Flask  
- Docker  
- Git & GitHub  

---

## ▶ How to Run This Project

### 1. Clone the repository
```bash
git clone https://github.com/Harshithgowda2004/docker-github-project.git
cd docker-github-project
```
